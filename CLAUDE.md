# Proyecto
App en React Native para el registro y ayuda al usuario que quiere tener rutinas de entrenamiento de running por ahora. Mas adelante se vera.

# Comandos
- Arrancar: npx expo start.
- Lint: npm run lint
- Tests: npm test

# Normas
- Todo en TypeScript estricto, nada de `any`.
- Solo componentes funcionales y hooks.
- Estilos con StyleSheet.create, nunca estilos inline.
- Componentes reutilizables en /components, pantallas en /app.
- Textos visibles para el usuario en español.
- Antes de instalar una dependencia nueva, pregúntame.
- Después de cada cambio, ejecuta el lint y corrige los errores.
